# 2026-06 目录迁移归档

本目录保存 tools 仓库旧布局的重组提案和当时使用的迁移脚本，仅用于追溯决策与审计历史。

## 重要说明

- `reorg-proposal.md` 描述的是迁移前的目录、耦合关系和执行建议，其中旧路径是历史快照。
- `migrate.sh` 依赖迁移前根目录中的哨兵文件与布局，**不可在当前仓库结构中执行**。
- 不要根据归档内容恢复旧入口，也不要把归档脚本作为当前安装或升级流程的一部分。
- 当前目录规则、模块位置和调用方式以根 [README.md](../../../README.md) 与 [docs/STRUCTURE.md](../../STRUCTURE.md) 为准。
